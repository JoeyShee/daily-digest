# Daily Digest

辉哥的商业感知入口。首页不再承担“把所有新信息展示出来”，而是先用 Repricing 分析把散乱信号压缩成少量判断：**什么正在被重新定价，以及它对 Build / 10x 意味着什么。**

原始 RSS、社区、课程、案例和想法继续保留在后台与专项频道，作为发现和求证材料；它们不再默认要求用户逐条阅读。

默认信息层级：

1. 一个今日主判断；
2. 最多少量候选判断；
3. 按需展开的证据层；
4. 原始信号库与历史专项频道。

Repricing 正式报告路径：`~/.hermes/data/repricing/reports/YYYY-MM-DD.md`。
