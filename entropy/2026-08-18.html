BloxInformer：Roblox wiki站峰值568万访问

📋 这生意是什么
广告主通过GAMURS广告网络（gdoubleclick、amazon-adsystem等）为Roblox玩家流量付费。核心是游戏玩家群体大、查询频繁、会回访。
规模：峰值568万月访问

🛤️ 怎么做到的
模板化每个游戏的wiki页→接'游戏名+wiki/codes/trello/discord'类长尾搜索→GAMURS媒体网络分发抬升（Destructoid等外部媒体推流）→内部链接循环→重广告栈变现。

⚡ 关键转折
意识到Roblox不是一个游戏而是一个游戏宇宙——每个热门体验都能长出一套wiki需求，页面规模天然巨大。用模板化生产方式，每个新游戏只需要改数据，不需要重写页面。

💰 为什么能赚钱
Roblox玩家经常搜索特定游戏的wiki、codes、trello、discord信息——官方不提供这些内容，搜索需求长期存在且高度碎片化。每个新游戏上线都会催生新一轮搜索。
玩家对特定游戏信息有强烈且反复的搜索需求，页面天然适合展示display ads。高频回访+大量页面=持续广告收入。GAMURS媒体网络提供分发和广告栈加持。

🔍 卡位分析
🧠 UGC游戏每个热门体验都能长出一套wiki需求，模板化生产页面规模天然巨大，关键是官方不覆盖SERP很空
👉 选一个中文UGC生态（如原神/崩铁），做模板化攻略wiki站测试3个月搜索流量

💡 辉哥可以做的方向
1. 做中文版游戏wiki站：覆盖原神/崩铁/鸣潮/明日方舟等热门手游，用模板批量生成攻略/codes/角色图鉴页，吃百度搜索长尾流量，接广告变现。
2. 做UGC游戏的SEO工具：帮游戏内容创作者批量生成wiki页和优化搜索排名，做成SaaS卖月费，对象是做游戏媒体站和攻略站的人。
3. 在小红书/抖音做「游戏攻略速查」账号矩阵：短视频引流到自有wiki站，wiki站接广告，形成'短视频获客+搜索承接+广告变现'闭环。
4. 做出海版游戏wiki站：覆盖Roblox/Minecraft/Fortnite等UGC游戏，英文SEO+AdSense变现。用AI批量生成初版wiki页，人工校准关键数据。
5. 卖「游戏wiki模板站」一键部署方案：包含wiki模板、codes extension、广告集成、SEO优化，收一次性部署费（999元）+ 月费维护（99元），卖给想做游戏媒体的团队。

🎯 一句话带走
UGC游戏的粉丝wiki是被严重低估的流量金矿——官方不做的内容，玩家自己会搜。

⚠️ 红灯提醒
依赖单一游戏IP，热度有周期性。

他做了9000个网站来吃SEO流量

▼

📋 这生意是什么
Mediavine/AdThrive广告主为搜索流量付费；需要提权的第三方SEO客户为外链位置付费。最终是搜索用户通过广告点击间接付费。
规模：9000个网站

🛤️ 怎么做到的
扫描过期域名数据库→筛选高权重+真实外链+垂直相关→竞拍购买（$5,000-$42,000）→AI批量产出SEO文章→接入程序化广告→出售外链位置→流量稳定后301重定向到主站→循环放大。

⚡ 关键转折
发现过期老域名的权重杠杆——别人花几年建的权威外链（来自顶级媒体），几千美元就能买过来直接用。The Hairpin收购案例证明：一个来自纽约客的外链比1000条垃圾外链更有价值。被Wired曝光后反而转型'AI+人工打磨'模式，公开承认灰帽成了最高级公关。

💰 为什么能赚钱
填补搜索结果中空白的长尾内容需求——用户搜索各类信息时需要'刚好够用'的答案。SEO客户需要高权重外链来提升自己网站的排名。
过期老域名自带权威外链（来自纽约客/BBC/福布斯等），相当于花几千美元就买到了别人花几年建起来的SEO权重。广告收入可观（The Frisky年收入峰值$500,000），外链出售是额外收入。

🔍 卡位分析
🧠 核心杠杆是过期老域名的权威外链，不是内容质量，数量本身就是护城河
👉 用GoDaddy/Sedo扫描过期域名，找DA>30+有真实媒体外链的，买一个做测试站

💡 辉哥可以做的方向
1. 搭建「过期域名筛选器」SaaS工具：自动扫描GoDaddy/Sedo/Flippa的过期域名，按DA/真实外链/价格/垂直度筛选打分，卖给SEO从业者，月费99-299元。
2. 做AI+人工的「SEO内容生产线」工具：AI批量生成初稿→人工审核校准→自动发布到站群，工作流自动化，卖给做程序化SEO的团队，按站点数量收费。
3. 在生财有术圈子开「程序化SEO实战营」：教批量做站+权重迁移+广告变现的完整链路，带学员从0到上线10个站，定价1999-3999元，靠技术背景建立信任。
4. 做「站群管理面板」：一个后台管理多个网站的域名到期提醒、内容发布排期、流量监控、广告收入统计，卖给管理50+站点的SEO从业者，月费199元。
5. 收购3-5个中文过期权威域名（如老牌博客/地方媒体），做垂直内容站试验，验证301权重迁移在国内的效果，成功后写成案例引流到付费社群。

🎯 一句话带走
程序化SEO的玩法：找到可标准化的内容模板，用数据驱动批量生产。质量门槛低但数量门槛高。

⚠️ 红灯提醒
Google对低质量批量站打击力度越来越大，纯量不保质会被惩罚。

八类高密度鱼池：钱不在产品里，在已经发生的行为里

▼

📋 这生意是什么
独立开发者、有技术背景想做副业的产品经理、生财有术圈子的成员、想做出海项目的创业者。核心特征是'有能力做但不知道做什么'。
规模：8类鱼池，每类都有判断标准

🛤️ 怎么做到的
内容型产品——通过公众号/小红书/生财有术传播框架方法论→建立'鱼池捕手'专家形象→引流到付费课程/社群/工具。框架本身的分类法天然适合做系列内容（每类鱼池一篇深度文）。

⚡ 关键转折
核心洞察：钱不在产品里，在已经发生的行为里——不要问'我能做什么'，问'哪里已经有人花钱/搜索/抱怨但没人好好做'。八类鱼池本质上是把'已经发生的行为'分类整理成可扫描的信号源，把选题从灵感游戏变成了工程问题。

💰 为什么能赚钱
独立开发者最痛苦的不是'做不出产品'，而是'不知道做什么'——需要一个系统化的选题判断框架来替代凭感觉想idea。现有框架要么太抽象（SWOT），要么太依赖个人灵感。
框架提供了可操作的判断标准和每日SOP（固定2小时捕鱼、抓100个信号、过滤到10个、选出1个验证），比'多想多试'更高效，直接降低试错成本。实操SOP从信号捕获到产品上线有完整路径。

🔍 卡位分析
🧠 钱不在产品里在已经发生的行为里，不要问'我能做什么'，问'哪里已经有人花钱但没人好好做'
👉 今天花2小时扫一遍Product Hunt热评和Reddit抱怨帖，记录3个高频痛点

💡 辉哥可以做的方向
1. 做「鱼池扫描器」工具：自动聚合Google Trends/Product Hunt/Reddit差评/Chrome插件差评/G2差评/小红书评论区的信号，用AI提炼高密度鱼池线索，每日推送top 10机会，月费99元，面向独立开发者。
2. 在小红书开「每日鱼池」系列账号：每天用1分钟视频拆解一个鱼池机会（如'今天Reddit上有人在骂XX太贵，这就是你的机会'），日更建立IP，引流到付费社群（年费999元）。
3. 做「迁移池」出海落地服务：帮国内已验证的小工具（如小红书数据分析、抖音封面生成器）做英文版/日文版上线，收取搭建费+收入分成，利用自己已有的出海经验。
4. 做「抱怨池挖掘器」：自动抓取Reddit/Chrome Web Store/G2/App Store的差评，用AI分类提炼'太贵/太慢/没有XX功能'等高频抱怨，生成产品机会报告，卖给独立开发者，月费199元。
5. 开「八类鱼池实战班」6周课程：每周深度拆解一类鱼池+布置实操作业（如第二周去Reddit找10条抱怨并选1条做MVP），带学员从0到上线一个小产品，定价1999元，用生财有术圈子冷启动。

🎯 一句话带走
不要问「我能做什么」，问「哪里已经有人花钱/搜索/抱怨但没人好好做」。鱼已经咬钩的地方，就是你应该去的地方。

把创业从"创造产品"重构为"管理一组高赔率下注"。世界每天在发生无数价值交换，工作是尽早进入这些交换，而不是站在交换之外把自己准备得越来越好。于是商人问的不是"哪个最好／一定能赚"，而是"哪个更值得下注"——像投资问赔率、不问哪只股票一定涨。套利＝发现别人没发现的交换不平衡（信息/时间/渠道/能力）。方向甚至被颠倒：不是"我创造价值所以别人付钱"，而是"有人愿意付钱，我们共同完成了一次价值创造"。边界：下注不等于乱赌，仍需最小验证。来源：8/3 商业反思。
