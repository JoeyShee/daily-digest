配料表-过敏原提醒产品名称 SnapCheck「一拍即判食物安全」文档范围 仅聚焦核心功能：相机扫描食品包装 → 3 秒内给出“是否安全可食用”结论。────────────────────────• 功能定义 ──────────────────────── 一句话 用手机摄像头对准食品包装拍一下，即可获得针对过敏原与慢病（糖尿病／肾病／高血压／痛风）风险的即时判定。 核心流程 拍照 → 本地 OCR 解析 → 成分/营养词典匹配 → 风险级别计算 → 结果页展示 全程≤3 秒，不要求任何手动输入。输出内容 • 整体风险灯号：绿色=安全、黄色=谨慎、红色=禁食 • 触发成分高亮：如“花生蛋白”“高钠” • 简短建议：例—“含乳糖，若乳糖不耐受建议少量试食” • 误判反馈入口：一句话描述 + 上传照片──────────────────────── 2. 目标用户 & 使用场景 ──────────────────────── 目标用户 • 严重食物过敏者（尤以坚果、麸质、海鲜为主） • 慢病患者：糖尿病、肾病、高血压、痛风 • 其直系亲属（帮孩子/老人购食）高频场景• 超市货架：挑选零食时举机扫码，判断是否能买 • 外卖/电商：对商品详情图或条形码截图执行“图片分享至 SnapCheck” • 聚会自助餐：对着餐盘标签拍照，快速筛掉高危食物 ──────────────────────── 3. 交互逻辑 ──────────────────────── 首页 ┌───────────────┐ │ [ 拍摄按钮 ] │ （仅一个主按钮，极简） └───────────────┘ • 顶部状态栏实时提示网络/离线包状态 • 右下角小图标：历史记录拍摄页 • 全屏取景 + 中央半透明识别框 • 底部快门键；长按自动连拍，首张识别成功即停识别中 • 识别进度环（0-100%） • 若 >2 秒仍未识别 → 提示“请靠近或对准配料表”结果页 ┌───────────────┐ │ 红色灯号 + “禁食” │ │ 花生蛋白、牛奶蛋白 │ （触发词 Chips） │ 建议：请选用不含坚果的替代品 │ │ [ 保存 ] [ 反馈误判 ] │ └───────────────┘ • 上滑查看更多：完整配料、营养表、法规召回信息 • 左划 → 返回拍摄页历史记录 • 时间轴卡片 + 灯号 • 顶部搜索栏可按名称/风险筛选 • 长按删除；右滑可分享结果截图误判反馈 • 两步：选择问题（成分漏检/误判）→ 可选文字说明 • 数据上传后提示“24 h 内更新”，增强信任──────────────────────── 4. 页面风格 ──────────────────────── 设计基调 • 诊室级安全感 + 生活化亲和力 • 主色： 绿色（安全）， 黄色， 红色 • 圆角、无边框卡片，留白充足，单手操作友好字体 & 图标 • 中文字体：HarmonyOS Sans / 思源黑体；英文字体：SF Pro • 图标线性、统一 24 px，确保老年人可见度动画 • 灯号从灰色→目标颜色渐变 300 ms • 识别进度环采用 Material You 风格可访问性 • 全局文字最小 16 sp • 支持系统深色模式；对比度符合 WCAG AA • 结果灯号同时显示文字，避免色盲误读──────────────────────── 5. 性能指标 ──────────────────────── • 首次冷启动 ≤2 秒 • 识别成功率（含进口 SKU）≥92% • 端侧耗电：连续 10 次扫描电量下降 <3% • 误判用户反馈闭环 ≤24 h 更新云词典──────────────────────── 6.
